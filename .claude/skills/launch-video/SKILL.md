# Launch Video Playbook

Source: adapted from an X growth-hacking thread claiming 250k–5M+ view launch videos from a monthly cadence. The core execution discipline (real video, sharp hook, format research, mobilize your network, relaunch at milestones) is sound and reused here. The coordinated-engagement mechanics in the original thread are **not** reused as-is — see "What needs adjusting" below for why, and what to do instead.

## Fit check — read this before doing anything else

This is a Track A tactic (see the `growth-playbook` skill for the track split) — it's built entirely around X/Twitter's algorithm and an English-speaking, terminally-online startup audience.

- **Fits**: `jumelleCafe`, `BeanPath`/`beanspath`, `co3data`, `coopmanager`, `AgriSight`, `CongoCSPC` — products whose buyers (EU coffee/cocoa buyers, exporters, NGOs/donors, hospital/health-system decision-makers) are reachable in English online.
- **Doesn't fit**: `kivukazi`, `kazi`, `TicketNavigator`, `aryv logistics`, `eazyconnect`, `cafekivucongo`, `boutique`, `chantierMobile` — none of these have meaningful customer presence on X. Point the user to `growth-playbook`'s Track B tactics (WhatsApp/TikTok/Instagram, "video > image" still applies, just not the X-specific mechanics below) instead.
- If asked to apply this to a Track B or single-client/internal project, say so rather than forcing an X-launch plan onto an audience that isn't there.

## What resonates (use as-is)

1. **Make a real video** — self-recorded screen capture or edited — a demo video reliably outperforms text/screenshots (this is also `growth-playbook` tactic #5).
2. **Open with a hook that stops the scroll**: "the first ever ___", "today we're replacing ___" — specific, comparative, or category-defining beats generic "excited to announce."
3. **Research what's currently working**: look at genuinely viral launches from the last ~60 days in the same niche via search, study opening lines, video pacing, and which quote-tweets performed. Only cite real examples found via an actual search — don't fabricate a plausible-sounding "10M-view launch" to justify a format choice.
4. **Give your genuine network advance notice** (investors, friends, past colleagues) of the exact launch date/time, with a clear ask — standard, legitimate startup practice, not manipulation.
5. **Treat every big shippable feature as its own launch moment** — matches `growth-playbook`'s launch-max tactic: relaunch at real milestones, not just once.
6. **A flop is cheap information, not failure** — swap the hook, relaunch next week. Iteration frequency matters more than any single post's performance.

## What needs adjusting before using this

- **Scripted quote-tweets + "get everyone to engage within hour 1" is coordinated engagement, not organic reach.** X's platform-manipulation policy covers coordinating with others to inflate engagement even when no money changes hands — accounts doing this can get individually or collectively down-ranked, which defeats the purpose. Reframe: tell your network the launch is happening and what the product does, and let them react/share in their own words. A handful of genuinely different reactions from people who actually looked at the product reads as more credible — to both humans and the algorithm — than several quote-tweets echoing the same script.
- **"Follow X's disclosure rules"** in the source thread is a real, non-optional requirement the moment anyone posting is paid or given free product for it — flag this explicitly to the user rather than letting it pass as a footnote. Don't set up paid/incentivized posts without confirming disclosure is handled.
- **Paid ads and a hired editor are real spend.** Don't treat "run ads after day 1" or "find an editor" as a default action — get the user's explicit sign-off first, same as `growth-playbook`'s caveat on paid placements.
- **Tool names in the source thread are unverified** — don't instruct the user to sign up for a specific named tool on my say-so if I can't confirm it exists. Suggest categories (a screen-recording tool, a freelance video editor) and let the user name their own, or ask if they already have one in mind.
- **Relaunching 3–5x/month only works when each relaunch ties to a real milestone.** For a credibility-sensitive audience — `CongoCSPC` selling into hospitals, `jumelleCafe` selling EUDR compliance to auditors/buyers — over-frequent hype-style launch videos can undercut trust rather than build it. Weigh the audience's sophistication before defaulting to max cadence.

## What to hand back when asked for a launch video plan

- The hook (one line, specific/comparative, not generic)
- The video structure: first 3 seconds, core demo, close
- 3–5 real reference posts from the last 60 days in-niche to model the format against — only if actually found via search; otherwise say research is needed rather than inventing examples
- The network-notification message: date/time, what the product does, an open-ended ask — not a script to copy-paste
- A check on whether this ties to a real milestone; if not, question whether it's launch-worthy yet
